# Лабораторная работа 2

## Задание

Создать функцию `isBalanced(str)`, проверяющую сбалансированность скобок
`()[]{}` в строке (например: `"{[()]}"` -> `true`, `"[(])"` -> `false`).

## Реализация

Опишите экспортируемую функцию, алгоритм и граничные случаи.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
